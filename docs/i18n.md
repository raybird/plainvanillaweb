# 🌐 多語系國際化實作指南 (i18n Service)

在原生 Web 中，為了讓應用支援多國語系，我們需要一個不需要依賴外部框架 (如 react-i18next) 且能夠響應式重繪的國際化模組。

本專案在 `lib/i18n-service.js` 中實作了一個基於 `BaseService` 的 **i18n 服務**，能自動載入 JSON 語系檔案、處理參數化翻譯，並與 `BaseComponent` 的反應式更新生命週期完美融合。

---

## 🛠️ 1. 語系檔定義

語系資料存放在 `assets/locales/` 目錄下的 JSON 檔案中。例如：

### `assets/locales/zh-TW.json`
```json
{
  "app": {
    "home": "🏠 首頁",
    "docs": "📚 技術手冊",
    "lab": "🧪 實驗室"
  },
  "greeting": "哈囉, {name}！歡迎回來。",
  "items_count": "您的購物車中共有 {count} 件商品。"
}
```

### `assets/locales/en-US.json`
```json
{
  "app": {
    "home": "🏠 Home",
    "docs": "📚 Docs",
    "lab": "🧪 Lab"
  },
  "greeting": "Hello, {name}! Welcome back.",
  "items_count": "There are {count} items in your cart."
}
```

---

## 💻 2. 在組件中使用翻譯

所有繼承自 `BaseComponent` 的組件皆內建了 `$t` 輔助方法（它是對 `i18n.t` 的便捷封裝）。

### 2.1 基礎翻譯
```javascript
import { html } from '../../lib/html.js';
import { BaseComponent } from '../../lib/base-component.js';

export class TitleComponent extends BaseComponent {
    render() {
        return html`
            <!-- 自動翻譯 app.home 對應當前語系的字串 -->
            <h1>${this.$t('app.home')}</h1>
        `;
    }
}
```

### 2.2 帶有參數 (Interpolation) 的翻譯
如果翻譯字串中包含動態變數（如 `{name}`），可以在 `$t` 的第二個參數傳入一個物件：
```javascript
render() {
    return html`
        <div class="user-welcome">
            <p>${this.$t('greeting', { name: 'Raybird' })}</p>
            <p>${this.$t('items_count', { count: this.state.cartCount })}</p>
        </div>
    `;
}
```

## ⚡ 3. 語系變更與反應式自動重繪 (Reactive Re-rendering)

這是本專案最精妙的部分：**當使用者切換語系時，所有頁面與組件都會自動更新文字，不需要手動重新整理網頁！**

其背後的運作機制如下：
1. **事件訂閱**：在 `BaseComponent` 的 `connectedCallback()` 中，會自動訂閱 `i18n` 的語系變更事件：
   ```javascript
   connectedCallback() {
       this._onLangChange = () => this.scheduleUpdate();
       i18n.on('change', this._onLangChange);
       // ...
   }
   ```
2. **事件觸發**：當使用者點擊語系切換按鈕，呼叫 `i18n.setLocale('en-US')` 時，i18n 服務會抓取新語系檔並 `emit('change')`。
3. **排程重繪**：`BaseComponent` 收到事件後，呼叫 `scheduleUpdate()`，排程在下一個畫格 (`requestAnimationFrame`) 重新執行 `render()`，將最新翻譯字串套用至 DOM 中。
4. **垃圾回收**：在 `disconnectedCallback()` 中，組件會自動移除該監聽器，防止記憶體洩漏 (Memory Leak)。

---

## 🛠️ 4. 手動呼叫與全域使用

若在非組件類別（如一般的 JavaScript 服務層）需要取得翻譯，可以直接導入 `i18n` 單例：

```javascript
import { i18n } from './i18n-service.js';

// 初始化並載入預設語系
await i18n.init();

// 手動取得翻譯
const greetingText = i18n.t('greeting', { name: 'Raybird' });
console.log(greetingText); // "哈囉, Raybird！歡迎回來。"
```
